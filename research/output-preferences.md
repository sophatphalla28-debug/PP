# Output Preferences — 민수투자 Weekly Topic Research

Standing rules for how to deliver "Research this week's topics" results.
Follow these every week in addition to the full research spec.

## Required final delivery format

After the full research (Top 15 with scores, Top 5, urgency, evergreen, content gaps),
ALWAYS end the reply with these two blocks:

1. **Full list** — all topic titles in one numbered list (1–15).

2. **Separate copy blocks** — each topic title in its OWN fenced code block,
   labeled `#1`, `#2`, … so the user can copy each title individually.
   Title only inside each block — no score, no notes, no extra text.

Example of block 2:

**#1**
```
[topic title only]
```

**#2**
```
[topic title only]
```

(…continue through #15)
